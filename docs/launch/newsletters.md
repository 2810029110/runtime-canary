# Newsletter Submissions

## English short description

Runtime Canary is an open-source pre-flight Doctor for coding-agent CLIs. It
goes beyond executable discovery and `--version` by running a deterministic
tool-use task in an isolated workspace, verifying exact file evidence, and
proving cleanup. Failures are attributed to stable layers such as
authentication, network, permissions, configuration, timeout, and evidence.
Current coverage is Codex live canary and Claude Code probe-only.

Repository: https://github.com/2810029110/runtime-canary

## 中文短介绍

Runtime Canary 是一个面向 Coding Agent CLI 的开源预检 Doctor。它不止检查
可执行文件和 `--version`，还会在隔离工作区中执行确定性工具任务、验证精确文件
证据，并确认清理完成。故障会被归因到认证、网络、权限、配置、超时或证据层，
并附带下一步建议。目前支持 Codex live canary 和 Claude Code probe。

项目地址：https://github.com/2810029110/runtime-canary
